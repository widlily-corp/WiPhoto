WiPhoto — высокопроизводительный десктопный органайзер, каталогизатор и фоторедактор профессионального уровня. Приложение спроектировано по гибридной архитектуре: многопоточный бэкенд на **Rust / Tauri v2** с пулом соединений SQLite и нейросетевым движком `tract-onnx` в связке с легковесным, аппаратно-ускоренным фронтендом на **Vanilla JS / WebGPU / CSS** в ультра-минималистичной дизайн-системе *Refined Minimal*.

## ⚡ Ключевые возможности (v5.1.4)

### 🧠 1. Локальный AI и семантический поиск (Smart Albums)
* **Семантический поиск CLIP:** Индексация фотобиблиотеки с генерацией 512-мерных векторных эмбеддингов через локальный граф `tract-onnx` (полностью оффлайн, без передачи данных в облако).
* **Поиск по естественному языку:** Мгновенная выборка фотографий по смысловым фразам (например, *"закат в горах"*, *"собака на снегу"*).
* **Умная дедупликация:** Вычисление перцептивных хэшей (pHash, 32-битное расстояние Хэмминга) и кластеризация через пространственный индекс BK-Tree.
* **Распознавание лиц:** Локальное детектирование лиц и группировка по персонам.

### 🎨 2. Неразрушающий редактор и синхронизация XMP Sidecar
* **Adobe Lightroom совместимость:** Двусторонняя синхронизация рейтингов, цветовых меток, тегов, метаданных и истории коррекций через файлы `.xmp`.
* **Атомарная запись на диск:** Защита от повреждения данных при сбоях питания и параллельных процессах с автоматическим разрешением конфликтов.
* **История правок:** Полное сохранение оригиналов фотографий и мгновенный откат любых изменений.

### 🚀 3. Аппаратное ускорение WebGPU (WGSL Shaders)
* **Мгновенный отклик ползунков:** Обработка экспозиции, контраста, температуры, оттенка, светов, теней, сочности и HSL-каналов через GPU-шейдеры WGSL без задержек основного потока.
* **Живая RGB и Luminance гистограмма:** Динамический расчет распределения тонов и каналов в реальном времени.

### 🔍 4. Профессиональный рабочий процесс (Pro Workflow)
* **Режим сравнения (Compare / Split View):** Параллельный просмотр двух и более кадров с синхронизированным панорамированием и зумом для отбора лучших дублей.
* **Навигационная лента (Filmstrip):** Быстрое переключение между кадрами в режимах лупы (Loupe) и редактора без выхода в общую сетку.
* **Интерактивный кадрировщик:** Свободное и фиксированное кадрирование (1:1, 16:9, 4:3, 3:2), поворот и отражение.

### 🖼️ 5. Виртуальная сетка (Virtual Grid) и Web Workers
* **Плавный скролл 50,000+ медиафайлов:** Отрисовка строго видимого диапазона DOM-узлов (DOM recycling, <60 активных элементов) с нулевыми утечками памяти.
* **Фоновые вычисления:** Сортировка, фильтрация и расчет геометрии сетки вынесены в фоновый Web Worker (`grid-worker.js`).
* **Zero-Copy стриминг:** Кастомный протокол `asset://` / `tauri://` с поддержкой Range-запросов и ETag-кэширования для прямого отображения без накладных расходов Base64.

### 🗺️ 6. Интерактивная гео-карта (Geo-Map View)
* **Leaflet + Supercluster:** Извлечение GPS-координат из EXIF и кластеризация десятков тысяч точек без подвисаний UI.
* **Быстрая фильтрация:** Выборка фотографий по географическим регионам, городам и местам съемки.

### 📦 7. Пакетная обработка и экспорт
* **Массовые операции:** Групповое переименование по шаблонам, изменение тегов, выставление оценок и перемещение.
* **Продвинутый конвертер:** Экспорт в JPEG, PNG, WebP, AVIF и JPEG XL (JXL) с настройкой качества, масштабированием и наложением водяных знаков.
* **Очистка EXIF:** Опциональное удаление метаданных и геолокации (`strip_exif`) перед публикацией.

### 🔄 8. Устойчивые OTA-обновления и Command Palette
* **Автоматические OTA-обновления:** Интеграция с `tauri-plugin-updater` и GitHub Releases, потоковое отображение прогресса загрузки, проверка контрольных сумм и автоматическое восстановление при обрыве сети.
* **Командная строка (`Ctrl+K` / `Cmd+K`):** Мгновенная навигация, вызов функций, горячие клавиши (F2 — переименование, Ctrl+E — экспорт).

## 🛠️ Стек технологий

* **Desktop Runtime:** [Tauri v2](https://v2.tauri.app/) (Rust 2021 Edition)
* **Frontend:** Vanilla ES6+ JavaScript, WebGPU (WGSL), Web Workers, Vanilla CSS
* **База данных:** SQLite 3 с пулом соединений `r2d2` и векторным хранилищем
* **Машинное обучение:** `tract-onnx` (Open Neural Network Exchange оффлайн-рантайм)
* **Графика и форматы:** `image` 0.25 (JPEG, PNG, WebP, AVIF, TIFF, BMP, GIF, ICO), `jxl-oxide` (JPEG XL), `kamadak-exif`
* **Картография:** Leaflet 1.9 + Supercluster
* **Тестирование:** Node.js Built-in Test Runner (`node:test`, `node:assert`, `node:vm`) + Rust Cargo Test Framework

## 🚀 Быстрый старт

### Системные требования
* **Node.js** (v22.0.0 или новее)
* **Rust & Cargo** (1.75.0 или новее)
* Системные зависимости Tauri (см. [руководство Tauri](https://v2.tauri.app/start/prerequisites/))

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
# Терминал 1: Статический дев-сервер
npm run dev

# Терминал 2: Приложение Tauri с горячей перезагрузкой
npm run tauri dev
```

### Запуск полного набора тестов
```bash
# Тесты фронтенда (117 тестов в песочнице VM):
npm test

# Линтинг кода фронтенда:
npm run lint

# Интеграционные и стресс-тесты бэкенда Rust (74 теста):
cargo test --manifest-path src-tauri/Cargo.toml
```

### Сборка релизного дистрибутива
```bash
npx tauri build
```

## 🏛️ Инженерные стандарты и архитектурные принципы

1. **Refined Minimal UX/UI:** Никакого визуального мусора. 1px hairline-разделители, строгая типографика (Inter, JetBrains Mono), физически корректные пружинные анимации на GPU (`transform`, `opacity`).
2. **Zero-Copy & Low-Footprint:** Передача бинарных данных через протоколы Tauri минуя Base64-кодирование.
3. **Строгая изоляция и плоская логика (Flat Logic):** Ранний выход из функций (Early Returns), глубина вложенности не более 2 уровней, централизованное логгирование ошибок через `Logger.error`.
4. **100% Hermetic Testing (AAA Pattern):** Все тесты изолированы, не зависят от внешних веб-сервисов и используют безопасные временные директории.
