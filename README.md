# WiPhoto (v5.0.0)

[![WiPhoto CI](https://github.com/widlily-corp/WiPhoto/actions/workflows/ci.yml/badge.svg)](https://github.com/widlily-corp/WiPhoto/actions/workflows/ci.yml)
[![Version](https://img.shields.io/badge/version-5.0.0-blue.svg)](package.json)
[![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey.svg)](src-tauri/tauri.conf.json)

Профессиональный, высокопроизводительный менеджер и редактор фотографий для десктопа. Построен на базе **Tauri v2**, **Rust** (высокопроизводительный многопоточный бэкенд) и **Vanilla JS / CSS** (фронтенд с ультра-минималистичной дизайн-системой Refined Minimal).

В версии **v5.0.0** добавлено: Умные Альбомы (локальный семантический поиск CLIP), Неразрушающее редактирование (двусторонняя синхронизация XMP Sidecar), Карта с кластеризацией (Leaflet + Supercluster), Zero-Copy архитектура (протокол `tauri://`), тотальный редизайн UI (Refined Minimal + Command Palette) и OTA-обновления.

---

## 🚀 Быстрый старт

### Требования к окружению
* **Node.js** (v22+)
* **Rust & Cargo** (1.75+)
* Системные библиотеки для Tauri (подробнее см. на [tauri.app](https://tauri.app/start/prerequisites/))

### Установка зависимостей
Запустите в корневой директории проекта:
```bash
npm install
```

### Запуск в режиме разработки (Hot Reload)
```bash
npm run dev
# Сервер статики запустится на 1420 порту, после чего выполните:
npm run tauri dev
```

### Запуск тестов (CI / Локально)
```bash
# Тесты фронтенда (Node.js built-in runner)
npm run test

# Тесты бэкенда (Rust Cargo test)
cargo test --manifest-path src-tauri/Cargo.toml
```

### Сборка финального дистрибутива
```bash
npx tauri build
```

## 🛠️ Архитектура и Ключевые Оптимизации (v5.0.0)

### 1. Умные Альбомы (Семантический поиск CLIP)
Локальный интеллектуальный поиск по фотографиям с использованием модели машинного обучения CLIP (через `tract-onnx`). Векторные эмбеддинги сохраняются в SQLite, позволяя искать изображения по текстовому описанию (например, "собака на пляже") **полностью оффлайн**.

### 2. Неразрушающее редактирование (XMP Sidecar)
Двусторонняя синхронизация метаданных (рейтинги, метки, теги, история редактирования) с помощью `.xmp` файлов. Формат совместим с Adobe Lightroom и другими профессиональными редакторами.

### 3. Интерактивная Карта (Geo-Map View)
Извлечение GPS-координат из EXIF и отображение фотографий на карте (Leaflet + OpenStreetMap). Используется библиотека Supercluster для плавной работы и кластеризации тысяч маркеров при масштабировании без зависаний.

### 4. Zero-Copy Архитектура
Для максимальной производительности интерфейса передача тяжелых Base64-строк из Rust в JS была заменена на кастомный протокол Tauri (`tauri://`). Бинарные данные изображений стримятся напрямую в HTML-теги `<img>`, радикально снижая потребление оперативной памяти V8.

### 5. UI "Refined Minimal" & Command Palette
Дизайн-система переработана в строгий "Linear/Stripe" стиль. 
* Использование hairline-разделителей (1px) вместо теней.
* Монохромная типографика (Inter / JetBrains Mono).
* Встроена глобальная Command Palette (вызов по `Ctrl+K`).
* Анимации переведены на GPU (`transform` / `opacity`).

### 6. Встроенные OTA-обновления
Интегрирован `tauri-plugin-updater` для автоматической проверки новых релизов на GitHub. Пользователю отображается элегантное модальное окно со срендеренным Markdown Release Notes и возможностью установки "в один клик".

### 7. Виртуальная Сетка с DOM Diffing (Virtual Grid)
Для обработки библиотек объемом 10,000+ медиафайлов без утечек памяти отрисовывается только видимое окно просмотра. При скролле карточки переиспользуются точечно.

## 🎨 Стандарты разработки и кодстайл

### Conventional Commits
История изменений Git должна быть кристально чистой:
* `feat(ui): ...` — внедрение новой визуальной функциональности
* `fix(scanner): ...` — исправление багов
* `test(backend): ...` — добавление или изменение тестовых сценариев
* `refactor(layout): ...` — рефакторинг стилей и верстки

### Чистота кода
* **Плоские условия (Early Returns):** Избегайте вложенных блоков `if-else`. Выходите из функций как можно раньше.
* **Анимации:** Анимируйте только `transform` и `opacity` (рендеринг на GPU).
* **Никаких `any` или скрытых ошибок:** Пишите строгие типы, всегда логгируйте перехваченные исключения через `Logger.error(...)`.
